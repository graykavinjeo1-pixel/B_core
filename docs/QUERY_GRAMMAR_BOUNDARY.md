# Shared event-query grammar boundary

This increment addresses observation -> interpretation -> grounded response.
It does not establish general natural conversation or autonomous concept growth.

## Single interpretation used across the product path

- Role nouns with Korean particles and question/request morphology compile to
  query gaps, including multiple requested roles. The parser preserves the
  indexed predicate and explicit arguments, not a whole-sentence answer.
- Long-form Korean negation and English auxiliary negation preserve polarity.
- Supported English passive morphology maps to the same attributed event roles
  as active voice. Participle forms are lexical knowledge, not new concepts.
- The conversation contract recognizes a parsed event query as information
  seeking. A nominated diagnostic/action cannot replace its answer obligation.
- For recognized event queries with event memory, generic nearest-noun and
  action-ellipsis rewriting do not own the text. The event QA compiler binds
  references through source-attributed roles and validates the resulting proof
  of where each answer value came from.
- Nominal contrast corrections can replace a unique old role value in a unique
  compatible prior event. Missing/ambiguous antecedents cannot be invented.
- Lexical definition grounding requires an explicit alias subject. An unquoted
  adnominal verb before Korean 'meaning' is not itself an alias to learn.

## Acceptance and limits

Retain previous failures, run library tests, CLI regressions and an additional
fixed post-implementation query-grammar probe without runtime tuning to it.
Record partial failures separately. No arbitrary language-quality percentage.

The broad unseen-language suite is now development evidence, not blind data.
Its indirect listening requests, affective reactions, some corrections,
conditional reasoning and topic transitions are not covered by this increment.
Unsupported questions may still encounter other legacy paths. No claim is made
that all reference rewriting or all pragmatic routing is solved.

Sending does not prove confirmed receipt. A lexical receive/send similarity
must not create a delivery fact that was not observed.

Conversation state schema is 37; response schema is 28. Start a new session for
this build. Automatic stored-state migration, service restart, commit, push and
recursive source mutation are not part of this change. Root/package source
parity is checked only for changed files; package is not independently rebuilt.
