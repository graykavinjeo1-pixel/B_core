# Bounded conversational continuity repair

This engineering increment protects the observation -> attributed memory ->
interpretation -> response path. It does not promote concepts or open a research
stage, autonomous mutation, network learning or execution authority.

## Completion gates

- Ordinary Korean multi-sentence conditions do not crash or cross clause bounds.
- Active/nominal/passive questions preserve predicate identity and entity roles.
- All requested roles in a multi-slot question reach the output and validator.
- Explicit correction selects the same event; earlier input remains auditable.
- References in new reports bind to unique attributed context, not generated text.
- Social turns preserve relevant focus; ambiguous references request clarification.
- Stated conversational preferences receive a listening response, and follow-up
  intention/condition questions retrieve the user's recorded content.
- Existing regression suites, the preserved 14 exploratory scenarios and new
  structural substitutions pass. Runtime code stays frozen for final evaluation.
- Unit tests, formatting, clippy, original executable and scoped package parity pass.

Success means this bounded set of conversational paths works. It is not evidence
of unrestricted conversation, human cognition, or GPT-level general understanding.
No global percentage is inferred from these developer-controlled checks.
