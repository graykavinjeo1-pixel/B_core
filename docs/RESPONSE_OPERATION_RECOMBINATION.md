# Response operations, exclusion, and recombination

This repair advances observation -> attributed memory -> interpretation ->
response. It is human-authored Rust engineering, not autonomous semantic
discovery or a new research stage.

## Product boundary

ConversationContract already retained both Summary and Explain request effects.
The scalar content-slot answer path dropped one. Explicit response-content
effects now also establish an information obligation, even in imperative Korean
without a question mark.

DiscourseAnswerIR.response_parts preserves ordered answers to matrix operations.
The bounded partition admits 1–8 positive operations from at least two recognized
matrix operations, including explicit negative exclusions. Embedded content,
quoted/report roots, conditions and external task roots are not silently turned
into response-only operations. Single-operation behavior remains on its existing
path.

Each leaf retains its own query, evidence and claims, and is generated separately.
The parent combines all leaves, including explicit gaps. Validation rederives
the partition, rejects removed/reordered parts, checks exact aggregate claims and
evidence, regenerates leaf and combined surfaces, and checks current memory.
Nested batches are forbidden. A unique event reference across the answer may
supply follow-up focus; multiple different events are not silently collapsed.
No generated reply becomes a memory premise.

Explicit causal source spans can supply an ordinary parsed event plus a cause.
The event grammar still must consume the event span. A clause observation and its
enclosing causal observation can be one event only when actor, turn, source span,
modality, polarity and event roles agree. Their stored records remain intact.
Recap morphology, articles and prepositions use the event span, not words from
its causal argument.

Prohibitive imperatives retain negative polarity and prohibited modality.
A quotation boundary cannot override the prohibition. Inflected matrix
information verbs are not query topics. English acknowledgement is lexical
interaction knowledge, realized through the existing acknowledgement concept;
it does not grant task execution permission.

## Evidence and limits

Adapter library 685 and dockable core library 29 tests pass, together with six
existing CLI regression suites, formatting, clippy and API build.
The frozen developer evaluation has 11 scored requests over 18 turns: 5 full,
3 partial and 3 failed. It is not independently blind or a GPT comparison.
The original 50-turn development outputs are unchanged. The earlier M10
negative-explanation/acknowledgement failure is fixed; M09's recap remains unmet.

This is not unrestricted natural conversation. Subqueries still pass through
language parsing: politeness/function words and possessive ellipsis can defeat
target retrieval. Korean connected predicates, mixed response/task requests,
unknown event predicates and general listening requests remain incomplete.
Two missing obligations can currently produce duplicate, mechanical gap replies.
Preserving the obligations is necessary but does not make those replies natural.
