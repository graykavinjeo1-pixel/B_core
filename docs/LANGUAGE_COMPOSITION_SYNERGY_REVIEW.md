North Star의 관측 → 의미 구성 → 기억 → 판단 경로를 대상으로 한다.

## 실제 확인한 것

- 현재 네이티브 실행 파일에서 기존 한·영 16개 동일 입력 대조를 재실행했다.
  제공 의미 계약/어휘 등록 전 0개, 등록 후 16개가 해당 의미 ID와 참여자로 답했다.
  이것은 기존 경로의 재사용 증거이지, 새 문법 학습이나 자유대화 점수가 아니다.
- 다른 실험의 순수 Rust `SurfaceModel`을 별도 임시 Cargo 프로젝트에서 실행했다.
  사전학습 모델/말뭉치를 가져오지 않고 반갑/고맙 활용 관측 두 개만 제공했다.
  새롭/아름답/부드럽 활용은 맞았고, 좁+어요는 ‘조워요’로 오일반화했으며,
  넓+어요는 후보가 없었다. 모든 결과는 accepted=false인 후보였다.
  새롭은 원래 단위검사에도 있는 대상이다. 이 다섯 항목은 독립 블라인드가 아니다.
- `syntax_binding::attach_candidates`는 학습한 문법 관계를 출처 범위에 연결하지만
  의미 역할은 미확정으로 남긴다. 일반적인 주어→행위자 매핑이나 사실 승격 기능은 아니다.

## 가장 유망한 결합점

말끝 수정만 먼저 붙이는 방안은 보류한다. 우선순위는 **학습한 문법 후보를 기존
어휘의 의미 계약 및 출처에 연결하여, 이미 있는 기억·정정·추론 경로가 소비하게 하는 것**이다.

현재 `WorldVocabularyIR::parse_form`은 정해진 문법 변형을 통해 등록 술어를 파싱한다.
새 어휘를 추가해도 새 어순·활용·생략 구조가 자동으로 지원되지 않는다.
한편 `SemanticRoleGraphIR`에서 담화 참여자와 기억으로 가는 경로와, world vocabulary에서
원자·전제·추론으로 가는 경로는 별개다. 첫 경로에 후보만 붙여 놓으면 둘째 경로의 능력이
늘었다고 할 수 없다. 새로운 병렬 추론기를 복제하는 것도 피한다.

재사용할 원본 자산은 의미 ID/역할 계약, 원문·범위 보존, 정정 이력, 근거 기반 추론,
담화 기억과 답변 계획이다. 상대 실험에서는 학습 가능한 문법·어형 관측 방식을 취한다.
기존 어휘 × 학습한 문법 구조 × 기억 속 관계가 보지 않은 조합에 함께 작용하는지가 목표다.
가능한 조합 수를 실제 정확도나 학습 속도로 환산하지 않는다.

## 첫 구현 단위의 조건 — 아직 구현하지 않음

1. 형태·문법 후보에 모델 ID, 원문 해시, Unicode scalar 범위, 근거, 미확정 상태를 유지한다.
2. 기존 사건/참여자와 명시적인 어휘·역할·태·범위 계약으로 후보를 검토한다.
   문법상 주어를 행위자로 곧바로 바꾸거나 높은 점수를 사실의 증거로 사용하지 않는다.
3. 기존 의미 분석이 남긴 미해결 부분만 보완한다. 충돌하는 해석은 보류한다.
   출처·범위 검사 없이 인용/조건/희망을 실제 사실로 바꾸지 않는다.
4. 채택한 의미는 기존 기억 등록과 추론을 거쳐 실제 후속 질문의 답을 바꿔야 한다.
   world 경로는 명시적인 등록 술어 계약과 정상 prepare/proof 검증을 별도로 유지한다.
5. 문장 생성 학습은 그 다음이다. 완성 문장을 덮어쓰지 않고 의미 계획 안에서 선택한다.

## 비교와 중단 기준

구현 전에 동일 어휘/입력/대화 이력으로 다음 모드를 고정한다.

- 원본만 사용.
- 학습 후보만 추가하고 의미로 채택하지 않음: 답이나 사실이 몰래 바뀌면 실패.
- 기존 의미 계약과 후보 해소를 결합: 미해결이던 역할이 실제 기억·후속 답변까지 연결되는지 확인.
- 어휘 등록만 추가: 문법 결합 효과를 단순 어휘 추가 효과와 분리.

추가로 기억/근거를 제거하면 후보와 표현만으로 답의 사실을 재생하지 못해야 한다.
처음 보는 어휘·역할 교환·구조 조합에서의 성공을 측정하고, 수동태·부정·정정·인용·조건·
불명 술어·변조된 출처 범위는 별도로 검사한다. 보류를 정답으로 합산하지 않는다.
후보만 늘거나 최종 의미/응답 개선이 없으면 채택하지 않는다. 최대 두 구현/검수 회차 후
미달이면 원인을 남기고 중단한다. 이 문서는 네이티브 통합 또는 성장 달성을 선언하지 않는다.

## 검수에서 막은 위험

- 현재 생성기의 `verify_generation`은 토큰/의미 노드 커버리지를 검사한 뒤 의미 해시를
  기록한다. `validate`의 결정적 형태 재현과 함께 기존 생성 경로를 보호하지만,
  새로운 학습 출력의 독립 의미 역검사와 같지는 않다. 해시가 같다는 이유만으로 채택 금지.
- 두 단어에서 찾은 형태 규칙도 적용 대상이 틀리면 오일반화한다. 이 관측은 전체 학습 모델의
  결함률이 아니다. 단어별 정답 문장 대신 활용 부류/적용 범위의 언어 지식이 필요하다.
- 상대 말뭉치 manifest는 productionApproved=false이다. 모델·말뭉치 통째 병합이나
  Python/Kiwi 실행 의존성 도입은 이번에 수행하지 않았다.
