## 무엇이 달라졌나

**언어 구조 관측으로 만든 후보가 기존 의미·기억·정정·추론 경로에 실제 연결됐다.**
등록된 한국어 능동 하다형 이항 술어에 한해, 목적어가 먼저 나와도 조사와 학습한
역할·위치 점수를 이용해 참여자를 보존한다. 기존 확정 해석은 덮어쓰지 않는다.

학습 자료는 완성 문장이나 정답이 아닌 격·역할·위치 관측 12개다. 평가에 사용한
동사 `지원/기여`와 인명은 관측 자료에 없다. 다만 의미 술어와 언어별 별칭은 기존
명시적 어휘 계약으로 등록해야 한다. 모르는 동사의 의미를 자동 획득한 것은 아니다.

연결 순서: 구조 관측 → Rust 점수 모델 → 기존 술어/역할 계약 → 원문 근거가 있는
의미 전제 → 기존 기억/정정/증명 → 기존 문장 실현.

## 활성화와 경계

기본 자동 활성화는 없다. 호스트가 대화 시작 전에 `UPDATE_WORLD_VOCABULARY`로
의미 어휘를 등록하고, `UPDATE_WORLD_SYNTAX_MODEL`로 관측과 모델 식별자/버전을
제공한다. 예시는 보고서 폴더의 `setup-resolve.json`이다. 학습/검증은 Rust에서 한다.
첫 대화 이후 모델 설치·교체는 거부하며, 실패한 설치는 기존 상태를 바꾸지 않는다.
관측 최대 128개, 모델은 대화별 불변이다. 모델만으로 술어·사실·권한을 만들 수 없다.

범위는 한국어 능동 하다형 두 역할과 격/어순이다. 일반 동사, 자유로운 생략 해소,
형태소 생성 학습, 자유대화 전체는 아직 아니다. 상대 실험 회로의 관측/점수화 아이디어를
적용한 것이며 해당 말뭉치나 모델 전체를 가져오지 않았다. LLM/교사 호출은 없다.
후보를 만드는 두 역할 문법과 조사 해석은 코드에 명시되어 있고, 학습하는 것은 그 범위의
역할·격·위치 지지도다. 따라서 새로운 문법 구조 자체를 발견하는 학습기로 보아서는 안 된다.

첫 구현 회차의 스택 초과는 추가 선택 필드를 Box로 옮겨 해결했고 실패 기록을 남겼다.
기존 `hada_question_morphology_is_unary_grammar_owned` 실패는 기대값을 바꾸지 않고
보존했다. 따라서 **이 연결 단위의 완료이지 전체 저장소 배포 승인이나 자유대화 완성이 아니다.**

## 증거와 복구

원시 대조·설치·출처 검사와 실행 파일/소스 해시는
`reports/language-cortex-completion/learned-role-bridge-2026-09-09/final_report.json` 및
같은 폴더의 개별 결과에 있다. 기존 사용자 변경이 있으므로 전체 Git diff를 되돌리지 않는다.
복구 자료의 검증 범위와 제한은 final_report의 rollback 및 해당 receipt를 따른다.

복구 준비에는 미흡한 점이 있다. 작업 전 전체 파일 사본을 보존하지 않아 임시 역변환이
시작 해시와 일치한 파일은 `world_dialogue.rs` 1개뿐이다. 나머지 3개는 복구 미검증이다.
현재 소스는 되돌리지 않았으며, 미검증 역패치를 자동 실행해서는 안 된다.
기능 평가 통과와 별개로 안전한 전체 소스 롤백 준비가 완료됐다고 주장하지 않는다.

기능 평가 후 변경은 Clippy를 위한 `cfg(test)`의 불리언 단언 표기 1건뿐이다.
기능 평가 실행 파일을 다시 빌드했다고 주장하지 않으며 당시 소스와 최종 소스 해시를
구분해 기록했다.
