# Requested effects and source relation preservation

The product goal remains natural conversation. This increment protects the
observation -> memory -> interpretation -> response path; it is not completion.

## Communicative force is not an execution effect

ConversationContractIR records RequestEffectBindingIR entries with a source
frame/goal ID, explicit-request-frame provenance, canonical predicate, intent,
effect domain and recipient node IDs. ResponseContent and TaskWorkflow describe
requested output/workflow domains, never permission to execute. Existing
whole-turn polarity, quotation, information-force and interaction constraints
still apply. Entries alone must not be consumed as an authorization ledger.

An indirect/polite request with only response-content effects no longer becomes
an independent task merely because it has request force. Other active task
frames are retained even when native single-goal selection is empty. Inferred
native goals do not independently grant imperative authority. An explicit
non-user recipient prevents silently treating a delivery request as a reply
solely to the current user. Recipient binding remains as reliable as the existing
role parser; unrestricted recipient/reference understanding is not established.

Summary verbs now identify SUMMARIZE with explanation/content intent, not
INVESTIGATE. In nominal requests, an `of` complement containing an event noun is
not promoted to another requested operation. The supplied grammar distinguishes
an assessment of recovery costs from coordinated assessment and recovery.

## Keep the relation when clauses are split

When clause ingestion drops an explicit causal binding, the containing positive
user report is retained alongside its fragments. This is one report represented
at two granularities, not independent causal corroboration. Its source compiles
to the same validated Cause binding; an explanation query can retrieve it.

The supplemental observation is restricted to high-confidence, non-question,
unquoted input whose observations are positive actual-world user reports, and
whose frames do not authorize a task. Negated, hypothetical, attributed-to-other
and mixed-command controls do not gain this whole-report observation. Actual
world classification is an attributed claim, not verified truth or permission.
Implicit/ambiguous causal connectives and disputed causal scope remain limited.

## Verification and deployment

Tests cover polite content requests, actual tasks, mixed effect retention,
recipient handling, effect-payload tampering, nominal complements, bilingual
causal recall, and question/quote/hypothesis/negation/task contamination controls.
Passing effect classification alone does not prove successful answer generation
or every obligation in a compound request. Frozen fresh failures remain failures.

Current state schema is 40, response schema 31. Use a new session or an explicitly
authorized migration. No service restart, migration, commit, push or semantic
promotion is implied. Scoped root/pakage parity is not an independent package
build. Historical reports retain their original versions and failed outcomes.
