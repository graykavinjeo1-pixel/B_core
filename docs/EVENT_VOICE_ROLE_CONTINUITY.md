# Voice changes order, not remembered event roles

## Product-path diagnosis

The active statement about repairing a file in a library already produced a
reported event with Agent, Theme and Location in epistemic memory. Dictionary
lookup also recognized `repair` and `repaired` with shared entry identities.
The location was not forgotten: the passive question grammar recognized only a
narrow agent/recipient form and never constructed the corresponding location
query. This corrects the earlier uncertainty about storage versus retrieval.

## Shared grammar

Passive observations and questions now use the same role assembler: grammatical
subject -> Theme; by -> Agent; to -> Recipient; from -> Source; in/at -> Location;
for -> Duration. English articles do not become part of the entity identity.
Negation remains part of the event and matching constraints. A stranded
preposition can denote a gap only in the requested role. Duplicate roles,
unconsumed phrases and ambiguous predicate parses do not produce a selected
event.

The existing dictionary supplies both regular past/participle morphology and
irregular participles. Passive syntax does not license an arbitrary verb or an
invented suffix. Truncated lexical lookups remain unavailable. No new dictionary
entries, sentence-specific dispatch, event consequences or promoted concepts are
introduced. The existing role projection answers from the same attributed event
in either voice; it does not turn a report into verified execution or truth.

Questions cover place/time/duration and agent/recipient gaps in the bounded
passive construction. Passive observations retain the existing explicit by-agent
requirement. General relative clauses, arbitrary tense/aspect nesting and
agentless passive observations are not claimed as supported by this increment.

## Coupled verification

Developer tests combine active-to-passive and passive-to-active retrieval,
regular and irregular participles, changed nouns, negation, mismatched event
arguments and unsupported forms. The native event-reference script includes
the new paths alongside all its earlier cases. Query turns must leave the
source epistemic records unchanged. End-to-end checks retain one generation and
one final sentence validation before separate replay validation.

This is grammar engineering over supplied lexical knowledge, not autonomous
concept emergence or proof of unrestricted natural conversation. Personality
and affect policy are unchanged; these may vary realization but not source roles.

Schemas: conversation state 109, response 105, discourse answer 36. Existing
persisted states are not automatically migrated. No service restart, deployment,
commit or push is performed. Only scoped files are mirrored to `pakage`.

## Native diagnostic limits

Additional, unclaimed-as-blind compositions transfer to `painted`, time and
duration queries. `opened` remains unresolved: the native lexical lookup finds
28 base-form `open` entries but zero `opened` entries, without truncation or a
full scan. The existing conservative regular-past rule omits uncertain
multi-syllable consonant-doubling paradigms. This is a separate lexical
inflection gap, not evidence that the new role query lost a stored event.
Its failed dialogue remains in the increment report; no permissive suffix guess
or sentence-specific replacement was added to conceal it.
