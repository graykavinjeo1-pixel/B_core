# Matrix requests and content arguments

This repair advances observation -> attributed memory -> interpretation ->
faithful response. A request to explain an event is not authorization to execute
that event. It does not amend canonical semantics or enable autonomous mutation.

## One structural boundary across consumers

- ClauseGraph records ContentComplement from a governing information predicate
  to its argument predicate. English interrogative complements and bounded Korean
  -는지/-었는지 type endings supply grammatical evidence, not answer templates.
- The content predicate remains in the frame, semantic-role and scope graphs.
  It is descriptive and non-authoritative; it is not a second task root.
- Pragmatic candidate selection and answer-only reselection admit independent
  matrix/coordinate clauses, not content predicates. Explain is no longer
  categorically excluded from indirect request selection.
- The native lexical circuit consumes the same boundary, with source-text and
  predicate-offset alignment. It retains the original event and adds scope
  evidence while withdrawing a wrongly nominated live goal. Unrelated events and
  unresolved ambiguities are not erased. Mismatched source surfaces are not
  silently aligned.
- LanguageCenter preserves the descriptive contribution. Argument relations do
  not become task-dependency relations in the dockable semantic reasoner.

No whole-sentence answer branch, target-entity exception, new predicate vocabulary,
canonical concept generation, or supplied reasoning solution was added here.
This is human-authored deterministic grammar engineering, not autonomous discovery.

## Information clauses under statements

`EmbeddedInformationStatementIR` provides a shared, bounded grammatical boundary
for cognition predicates with interrogative arguments and for English WH clauses
used as nominal subjects of an information assessment. Korean finite cognition
predicates use existing dictionary lemmas; WH markers, complement morphology and
matrix word order supply scope, not an answer template. The original source byte
span is retained even when case folding changes a character's byte length.

Conversation question force, event-question classification, legacy discourse
query parsing, utterance-goal nomination and implicit knowledge-gap projection
consume the same boundary. A subordinate why/what/failure does not independently
establish a user question or requested repair. The contract records the scope
decision. The observation and its original hash remain available.

The existing native content-complement reconciliation also consumes the exact
argument span. Matching lexical events remain in the graph as content, with
grammar evidence, but lose live-goal status. It does not delete their information
or authorize their execution. Independent or quoted commands, coordinate clauses,
explicit matrix questions and ambiguous bare remember imperatives are not consumed
by this statement grammar. They retain their existing paths or unresolved limits.

This is an interpretation-boundary repair, not complete knowledge-state modeling:
it does not prove an embedded event occurred or verify that a user knows its
answer. The first implementation covers pronoun-subject English cognition clauses,
bounded English information assessments, and supported Korean cognition endings.
Arbitrary nesting, named-subject English cognition, ambiguous implicit requests
and unrestricted conversation remain unestablished.

Conversation response 98 identifies the changed boundary. Generation 22 and natural
realization 37 retain one construction and one final completed-output check.
No extra answer generation, reply template, dictionary mutation, concept promotion,
deployment, persisted-state cleanup or migration is introduced. Older stored
interpretations need an explicit replay/migration decision before deployment.

## Reference demand follows the response act

An unresolved entity in an information-statement argument is not automatically a
reason to interrupt the speaker. The existing reference IR now exposes a bounded
acknowledgement eligibility check: every literal occurrence of every unresolved
surface must lie inside the shared grammatical content span. Matrix references,
synthetic gap markers, missing surfaces, questions and coordinated commands do
not qualify. Original byte positions are used, without replacing any referent.

The pipeline uses this permission only for an assertion with an acknowledgement
response goal, no selected live goals, no inferred goal and no action-state turn.
All other clarification causes remain active. The ambiguity list, unresolved
count and source graph are preserved; a source-hash-bound response trace records
the deferral. The existing action and grounding checks still see the unresolved
references. This does not turn the content into a verified premise or provide a
binding to a subsequent command. Information statements also cannot use a
signature-keyword fallback to invent a nominal discourse center. Participant
pronouns use the existing shared participant vocabulary and are not stored as
named entities by typed mention collection or the native circuit's capitalized-name
detector. Both consume the same pronominal classification, including when native
context falls back to lexical extraction from a stored proposition. Original
propositions remain recorded. Discourse centering checks the full utterance before
legacy clause segmentation can lose the matrix boundary.

Native action-context ambiguity can veto a turn only when an action or verified
result query actually consumes that context. Descriptive and corrective turns
retain their semantic consumer's own reference checks; an unused action-context
ambiguity cannot override a valid role correction. Explicit ambiguous action
requests still stop. This does not declare all descriptive references resolved.

Attribution also consumes the shared English matrix-subject boundary rather than
registering a subject-plus-modifier prefix as a person. This does not establish
the truth of the embedded content or the reported knowledge state.
The existing attribution lexicon recognizes past `knew` in this path but not
present `know`; subject-boundary support is not full attribution coverage. A
direct CLI probe also found that a subsequent pronoun may fail to reuse an
explicit file mentioned in a cognition statement. This remains unresolved and
must not be reported as general reference capability or natural-conversation pass.

Conversation response 99, state 106, attribution 4 and native circuit 6 identify these changes. There is no additional
output-generation or final sentence-verification pass. This is not unrestricted
reference resolution or rich memory of a speaker's knowledge state. Existing
generic acknowledgements remain a limitation. No service restart, persisted-state
migration, canonical edit, concept promotion, commit or push is part of this work.

## Content-local role extraction and nominal continuity

The role analyzer now intersects an embedded predicate's argument window with
the shared information-content span before reading pre/post-predicate words.
This does not require a native action lexeme for the matrix cognition predicate.
An absent matrix frame can no longer cause the matrix prefix to become the
embedded event's nominal agent. An interrogative infinitive without an overt
subject leaves that agent unbound; its infinitive marker is not an entity.

Explicit content nouns and overt embedded agents remain available to the role
graph and typed mention memory. Their mention does not establish the event as a
fact or authorize execution. A later command needs its own selected goal and
unambiguous target; multiple actual candidate objects remain ambiguous.

Role graph 4, conversation state 107 and response 100 identify this change.
No output rewrite, extra generation pass, new dictionary entry, persisted-state
migration or service deployment is introduced. This remains bounded grammatical
engineering, not proof of arbitrary conversation or complete cognition-state
memory. The earlier failed explicit-file diagnostic is preserved in its report;
new evidence must distinguish repaired nominal continuity from other unresolved
question-answer and realization limitations.

Lexical coverage is still unequal between native and compositional predicate
inventories. For example, a recognized native `modify` event need not have a
compositional role frame. The continuity test therefore checks retained explicit
noun evidence, absence of pseudo-entities and the subsequent grounded target,
without claiming all mentions passed through identical typed storage. Unifying
those inventories is not established by this repair.

Passive subjects now use the same nominal-subject extraction as active subjects;
voice assigns the patient role but does not make a WH clause introducer part of
the object's identity. The first direct passive diagnostic failed with a
`why the file` pseudo-entity and is preserved before this structural repair.

## Reference forms are mentions, not new objects

Typed entity collection now shares the conversation resolver's singular/plural
reference forms and the existing contracted-topic grammar. It also consults the
immutable sparse lexical index for whole Korean forms whose exact matching
entries are all pronouns. Partial matches, incomplete lookups and homographic
non-pronoun entries cannot establish this classification. No dictionary entry
or promoted payload changes.

This is a memory-identity boundary, not an antecedent resolver: excluding a
pronoun from new entity registration never selects its referent or authorizes a
task. The original utterance and reference evidence remain available. A resolved
reference must continue to use its existing entity, while an unbound reference
must not manufacture an object for the next turn. Contracted reference roots and
dictionary morphology are reused without adding whole-sentence dispatch.

Conversation state 108 and response 101 identify this change. It does not add an
output-generation or final sentence-validation pass. Existing stored pollution
is not silently erased; deployment or migration remains an explicit decision.

When a native ExplicitPriorTheme binding has already selected an entity on the
active semantic-goal path, compatibility ambiguity reconciliation consumes the
same singular-reference vocabulary. An inflected spelling cannot veto that
binding merely because a second whitelist omitted it. The bound target must exist,
must not be contrast-rejected, and must not itself be an unresolved pronoun.
No valid binding means no such permission; unhandled topic-form resolution
remains a separate limitation.

Native operation memory accepts replayable goals only from a grounded response
without unresolved references. A proposal that resulted in clarification cannot
manufacture its own future antecedent. Explicit entity observations remain
available independently, and an unresolved new request does not overwrite prior
accepted operation memory. This is a pre-generation memory-authority boundary,
not a second output validator or post-generation rewrite.

The native entity cache uses the same pronoun classifier as typed entity memory.
An explicit source span establishes that a word was uttered, not that a pronoun
is a newly identified object. Both stores must preserve that distinction.
