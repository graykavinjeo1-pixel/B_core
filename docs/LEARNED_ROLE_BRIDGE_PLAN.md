## 제품 결과

등록된 한국어 능동 이항 술어의 참여자 어순이 달라져도 명시적 조사와 의미 계약으로
같은 역할을 구성하고, 기존 사용자 전제 기억/정정/추론을 거쳐 후속 질문에 답한다.
먼저 목적격/처소격 하다형을 대상으로 한다. 문장 생성 학습·일반 사건 동사·자유대화 전체는
이번 단위 완료조건이 아니다. 기존 기능과 사용자 변경을 보존한다.

## 연결 계약

- 모델 관측은 답이나 완성 문장이 아닌 역할·격·위치의 언어 구조에 관한 제공 지도 정보다.
  모델은 일반 슬롯 결합 또는 특성 점수로 후보를 제시해야 한다. 특정 문형 분기를 켜는
  스위치만 추가하고 학습 회로라고 주장하지 않는다.
- 명시적 호스트 학습/주입으로 선택한 대화에만 적용한다. 모델 식별자, 출처, 버전,
  범위·재현 정보, 자원 상한과 비활성/관측만/결합 대조를 유지한다.
- 어휘·역할·조사·능동태·범위의 기존 계약으로 후보를 제한한다. 점수는 확률이나 사실의
  증거가 아니다. 확정된 기존 해석과 충돌하면 덮어쓰지 않는다.
- 원문을 완성 문장으로 재작성해 우회하지 않는다. 원문 근거를 유지한 의미가 기존
  prepare/memory/proof 경로에서 소비되어야 한다. 후보 필드만 추가하면 미완료다.
- 모델 단독으로 새로운 술어·사실·권한을 만들 수 없다. 의미 ID/기억/모델의 세션을 섞지 않는다.
- 기존 기억의 원문 재현이 모델 교체 때문에 달라지지 않아야 한다. 구버전 상태도 검증하거나
  명시적으로 거부해야 한다. 모델·말뭉치 전체 복사, Python/LLM 의존, 원격 호출은 없다.
