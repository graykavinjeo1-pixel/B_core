# Content operations and expression manner

Observation -> attributed memory -> interpretation -> faithful response is the
product path protected here. No canonical amendment, promotion, recursive source
mutation, external action, or broader capability claim follows from this repair.

## Ownership rules

- InteractionPreferenceIR retains response_manner separately from desired content
  mode. Concision cannot replace Summary or Explanation. An embedded English
  wh-complement in an explicit addressee request remains requested content.
- The existing response planner consumes local concision to reduce optional
  moves; required facts are not removed. This is not general abstractive shortening
  or proof of persistent style learning across arbitrary turns.
- A standalone length preference may own its acknowledgement only when it does
  not conceal a nominated operation. Complete listening/conversation clauses retain
  their exclusion semantics. V1 applied this veto to every interaction mode and
  regressed a negated-summary/conversation request; that run is preserved as failed.
- An explicit new content slot is not replaced by the previous question during
  reformulation. Previous focus supplies context, not a different operation.
- The bounded event operation can establish its own deictic argument using an
  active, source-replayed event. Only a validated successful recap satisfies the
  query-reference boundary. Generic ambiguity flags are not blindly erased and
  do not grant execution authority.
- Korean action nouns can take 부탁하다/부탁드리다 request morphology. The shared
  light-predicate grammar consumes the complete local tail and rejects negative,
  conditional and reported continuations. Operator identity remains distinct.

## Limits and deployment

This does not solve all modifier positions, multi-operation obligations, explicit
topic matching, event translation, passive realization, or targeted knowledge-gap
dialogue. Those failures must remain visible. The original broad dialogue goal is
not redefined as a pass on this narrower path.

V1 (state 42 / response 33) failed a retained dialogue regression and was not copied
to the package. The successor is state 43 / response 34. New sessions or an
explicitly authorized migration are required. No service restart/migration or
Git commit/push is included. Package source parity is not an independent build.

Reports, fresh developer evaluation and the preserved V1 failure are under
reports/language-cortex-completion/content_manner*. New failures are not silently
patched inside their frozen evaluation version.
