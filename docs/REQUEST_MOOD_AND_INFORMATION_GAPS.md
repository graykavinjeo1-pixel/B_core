# Request mood and missing information arguments

This increment improves the observation -> interpretation -> attributed memory
-> response path. Natural conversation remains the product goal, not a claim
established by a small grammar test.

## One contract, distinct mood and force

InteractionPreferenceIR now records Desiderative, Directive or
InterrogativeRequest mood separately from desired and excluded semantic modes.
Conventional addressee-directed questions can request conversation; interrogative
punctuation alone cannot force them into factual retrieval. Self-preference,
third-party, historical and quoted/hypothetical questions remain separate.

The same source compiler feeds contract derivation, memory ingestion and response
selection. Negative contrast arguments and desired scope are retained together.
An unknown coordinated imperative prevents exclusive conversational ownership.
Korean conjunctive requests are conservative: -고 싶다 is supported, unrestricted
multi-predicate commands are not certified as fully understood.

This is bounded inspectable grammar, not unrestricted pragmatic inference.
Lexical roles and inflections are supplied engineering knowledge, not autonomous
concept emergence. Entire evaluation sentences are not runtime lookup keys.

## Missing target is different from missing knowledge

After ordinary answer paths fail, a source-replayable query can identify an
unfilled explanation target or comparison operands. Every word remaining in
this classifier must be grammatical/deictic; unknown content is conservatively
treated as an explicit target, not erased. A prior substantive topic, answer
focus or attributed record prevents the context-free gap classifier from taking
ownership. Richer recovery across purely social turns remains unestablished.

The query kind, empty evidence/claims and source grammar are checked together.
Its output is a question graph with an operation and an unbound theme. Korean
and English share the graph; lexical roots, particles and modal question syntax
are realized separately. A clarification is not a factual answer or a promise
to execute a plan. It cannot claim missing-target status for an explicit target
such as an unknown named object.

## Deployment and evidence

Current state schema 40 and response schema 31 require a new session or separately
authorized migration. No persisted state migration, service restart, commit,
push, semantic promotion or recursive self-modification is part of this work.
Only touched source files are mechanically mirrored to pakage; unrelated edits
and sealed artifacts are preserved. Package parity is not an independent build.

Retained development fixtures and fresh wording probes are scored separately.
The same developer authors and evaluates these probes: they are not independent
blind evidence or a GPT comparison. See the dated request-mood report for actual
outcomes, failures and the tested executable hash. The broad goal remains active.
