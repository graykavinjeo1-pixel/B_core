# 0. CENTRAL SCIENTIFIC QUESTION

The existing autonomous improvement loop can:

* detect bottlenecks;
* synthesize repairs;
* improve itself;
* detect productive/open regimes;
* autonomously increase difficulty;
* adapt to harder work.

The current question is now stronger:

> When the existing difficulty substrate can no longer generate genuinely harder, mechanically verifiable work, can B_Core itself discover what kind of harder world/problem structure is missing, create a new difficulty substrate for it, validate that substrate independently, and continue self-directed improvement?

This is NOT:

> increase the difficulty number.

It is:

> increase the actual space of learnable, verifiable problems.

```text

additional generator effort does not create new capability pressure
```

These are evidence examples, not fixed thresholds.
